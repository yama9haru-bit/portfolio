## 解決した課題

AI関連の最新情報をX（旧Twitter）から毎日収集して把握する必要があったが、手動での情報収集には限界があった。また、収集した情報を読みやすい形式で毎朝受け取る仕組みが必要だった。Mac mini障害時にも配信が止まらない復旧メカニズムも必要だった。

## 技術スタック

| 分野 | 技術 | 役割 |
|------|------|------|
| データ収集 | Python | X(Twitter)からのAI関連情報自動収集 |
| コンテンツ整形 | HTML | 収集情報の読みやすいHTMLフォーマット化 |
| 定期実行 | Cron | 毎日の自動実行スケジューリング |
| 配信 | Gmail API | HTMLメールとしての自動送信 |

## 実装内容

X（旧Twitter）からAI関連情報を自動収集し、HTML整形してGmailに毎日配信するパイプラインを構築した。

- **自動収集**: PythonでXからAI関連のポストを自動収集する。
- **HTML整形**: 収集した情報を読みやすいHTMLフォーマットに整形する。
- **定期実行**: cronによる毎日の自動実行を設定。
- **Gmail送信**: Gmail APIによるHTMLメールの自動送信。
- **障害復旧**: Mac mini障害時の復旧メカニズムを構築済みで、障害後も自動的に配信が再開される。

## 成果・効果

- 毎日運用中のパイプラインとして、AI関連情報の自動収集・配信を実現
- 手動情報収集の工数をゼロにし、毎朝の情報把握を自動化
- HTML整形により、読みやすい形式での情報配信を実現
- Mac mini障害時の復旧メカニズム構築により、配信の継続性を担保
